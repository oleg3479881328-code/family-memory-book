# Фотоальбомы людей

Здесь будут храниться подпапки с фотографиями для конкретных людей.

Рекомендуемый формат папки: `фамилия-имя-отчество` или существующий id из `data/family.js`.

Пример:

```text
assets/photo-albums/anna-kuteinikova/
assets/photo-albums/dmitry-kurenev/
```

Фотографии внутри подпапок лучше называть по смыслу или дате: `1938-family.jpg`, `portrait-01.png`, `document-passport.jpg`.
