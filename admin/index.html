Локальная админка

Семейная книга памяти

Состояние

Админка подключается к локальному серверу. Выберите человека, добавьте фото и нажмите «Сохранить изменения».

Локальный сервер не отвечает. Запустите файл start-admin.bat.

Обновления папок

Проверка новых фото и видео, затем синхронизация в сайт.

Пока можно проверять вручную. После синхронизации публикуй отсюда же.

Нажмите «Проверить обновления», чтобы увидеть новые файлы в папках фотоальбомов.

Люди

Карточка человека

Имя, даты, заметки и фотоальбом.

Выберите человека слева, чтобы начать редактирование.

Эта версия сохраняет изменения в data/family.js и data/photo-albums.js и предназначена только для правки уже существующих карточек и их фотоальбомов.
