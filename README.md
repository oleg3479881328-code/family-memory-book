# Книга памяти семьи

Статический сайт для GitHub Pages: интерактивная родословная, разделы мемуаров и фотоархив.

Сайт объединяет семейные материалы в одном месте:

- родословное дерево;
- карточки людей;
- дословные русские мемуары;
- фотоархив;
- данные, извлечённые из исходного DOCX-документа.

## Статус проекта

Статус: рабочий статический сайт.

Текущая документация должна рассматриваться как maintainer-facing documentation — документация для сопровождения проекта человеком или ИИ.

## Локальный просмотр

Минимальный способ:

1. Откройте `index.html` в браузере.

Альтернативный способ:

1. Запустите любой статический сервер из корня проекта.
2. Откройте локальный адрес сервера в браузере.

## Карта репозитория

```text
index.html                  Главная HTML-страница сайта
styles.css                  Основные стили сайта
data/family.js              Структурированные данные родословной
data/memoirs.js             Разделы мемуаров, извлечённые из DOCX
assets/photos/              Фотоархив, извлечённый из DOCX
vendor/family-chart/        Локальная зависимость для отображения родословной
tools/extract_docx.py       Скрипт извлечения текста и фото из DOCX
```

## Важные материалы

- `data/family.js` — структурированная родословная.
- `data/memoirs.js` — русские разделы мемуаров, извлечённые из DOCX без редактирования текста.
- `assets/photos/` — изображения из DOCX.
- `tools/extract_docx.py` — повторяемое извлечение материалов из исходного документа.

## Важные правила сопровождения

- Не выдумывать семейные факты.
- Не переписывать текст мемуаров без явного указания.
- Не менять родственные связи без источника.
- Не удалять фотографии без явного решения владельца проекта.
- Не редактировать сгенерированные/extracted files без понимания источника и процесса генерации.
- Любые изменения данных должны быть проверены вручную.

## Известный риск

`tools/extract_docx.py` использует локальный путь к DOCX-файлу на компьютере владельца проекта.

Перед повторным запуском скрипта нужно проверить путь к исходному DOCX и убедиться, что файл доступен локально.

## Для человека

Начните с просмотра сайта через `index.html`, затем изучите структуру данных в `data/` и правила сопровождения.

## Для ИИ / Codex

Перед любыми изменениями сначала прочитать:

1. `PROJECT_ENTRYPOINT.md`
2. `PROJECT_STATE.md`
3. `PROJECT_RULES.md`
4. `docs/CODEX_HANDOFF.md`

Не начинать изменения без explicit handoff packet — явного пакета задачи с целью, областью изменений, запретами и критериями приёмки.
