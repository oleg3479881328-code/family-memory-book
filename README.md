# Книга памяти семьи

Статический сайт для GitHub Pages: интерактивная родословная, разделы мемуаров и фотоархив.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический сервер из корня проекта.

## Материалы

- `data/family.js` — структурированная родословная.
- `data/memoirs.js` — русские разделы мемуаров, извлечённые из DOCX без редактирования текста.
- `assets/photos/` — 15 изображений из DOCX.
- `tools/extract_docx.py` — повторяемое извлечение материалов из исходного документа.
